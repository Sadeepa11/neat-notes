# Neat Notes — React Website

A responsive pastel-pink website for the **Neat Notes** handwritten notes and stationery page.

## Included
- React + Vite
- Responsive desktop, tablet and mobile layout
- Pastel pink / cream design
- Services section for handwritten notes, letters, graphs and custom writing
- About section, ordering steps and contact CTA
- Generated Neat Notes logo and cover artwork in `public/images`

## Run locally

1. Install Node.js (LTS) if it is not already installed.
2. Extract this project folder.
3. Open a terminal inside the `neat-notes-react` folder.
4. Run:

```bash
npm install
npm run dev
```

5. Open the local URL printed by Vite (usually `http://localhost:5173`).

## Build for deployment

```bash
npm run build
npm run preview
```

The production-ready website is generated in the `dist` folder.

## Customise before publishing
- In `src/main.jsx`, replace `https://www.facebook.com/` with the actual Neat Notes Facebook Page URL.
- Update the services and wording to match the page's real offerings.
- Deploy the project to Vercel, Netlify or another static hosting service.

## Tech stack
React, Vite, JavaScript, CSS, Lucide React icons.
